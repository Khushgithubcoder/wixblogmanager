Zero-Credential Integration

Connect Your Wix Website

Connect your Wix account securely without ever sharing your Wix email or password. Access can be revoked from your Wix account at any time with one click.

Method 1: Site-Scoped Wix API Key (Direct & Self-Serve)

Recommended
1
Open API Keys Manager in your Wix Account:
Log into Wix and navigate to Account Settings → API Keys Manager (or your site's developer settings).
2
Generate New Key with Required Scopes:
Select Manage Blog (to create/edit/publish posts), Read Site Properties, and Read Members.
3
Scope to One Site:
Under Site Access, select only the specific website you want us to manage. Copy the key immediately (Wix shows it only once).
4
Get Site ID:
Found in your Wix Dashboard browser URL: wix.com/dashboard/{SITE_ID}/...

Method 2: Wix App OAuth 2.0 (1-Click App Install)

App Flow

If you are connecting via a registered Wix App, you can install the app directly onto your site with a single authorization click.
