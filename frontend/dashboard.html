Zero-Credential Security Architecture

The client never shares their Wix email or password. Access is granted either via a Site-Scoped API Key or the Wix App OAuth 2.0 flow. All tokens and keys are encrypted at rest with AES-256 (Fernet) in PostgreSQL and decrypted strictly in memory during live Wix API calls.
